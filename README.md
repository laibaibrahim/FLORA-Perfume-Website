# FLORA Perfume Website — Architecture Note

### 1. Website Pages
FLORA perfume Website contains 14 pages:
- Home
- Our Story
- Shopping Bag
- Checkout Preview
- Shop All Fragrances
- Contact
- Gallery
- Fragrance Gift Sets
- Fragrance Guide
- Men's Fragrances
- Search
- Signature Fragrance
- Wishlist
- Women's Fragrances

### 2. Navigation
The website uses navigation menus and links to connect different pages. Users can navigate to different sections, including Shop, Discover, Contact, Search, Wishlist, and Shopping Bag. CSS-based menu controls help manage navigation on smaller screens.

### 3. Use of CSS
CSS is used to style the website, including colors, fonts, layouts, spacing, buttons, images, and navigation menus. Flexbox, CSS Grid, and media queries are used to create a responsive layout for desktop, tablet, and mobile screens.
